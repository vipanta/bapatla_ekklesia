# Product cover pictures

Every one of the twelve titles in the store has its own picture file in this
folder, named after that title's slug. To change one, **upload your picture with
the same name** — the shelf and the product page show it on the next build, and
nothing else is edited.

- Any shape is fine: the frame holds the whole picture rather than cropping it.
- `.webp`, `.jpg`, `.png` or `.svg`. About 800px wide, photographs saved as
  `.webp`.
- Replace a file by uploading one with the same name; delete a file and that
  title goes back to its drawn cover.
